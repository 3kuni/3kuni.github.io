ノート印刷システム仕様書

概要

ObsidianノートをWeb公開（QRコード付き）+ A4印刷するシステム。Claude Codeから1コマンドで全フローが実行される。

フロー

「このノートを印刷して」（Claude Codeへの指示）
    ↓
① Markdownノートを読み取り → HTML変換
② UUIDv4ベースのURLでGitHub Pagesにデプロイ
③ QRコード生成（公開URLから）
④ ノート本文 + QRコード を A4レイアウトで合成
⑤ Chrome headlessでPDF変換 → lpコマンドで印刷

構成ファイル

ファイル 役割
~/.local/bin/obsidian-print-note.py メインスクリプト
~/dev/3kuni.github.io/p/{uuid}.html 公開されたノートHTML
~/dev/3kuni.github.io/p/manifest.json 公開ノート管理台帳

コマンド

基本（公開 + 印刷）

python3 ~/.local/bin/obsidian-print-note.py --file "ノートのパス"

オプション

フラグ 効果 デフォルト
--expires N 有効期限をN日に設定 30日
--no-print PDF生成まで（印刷しない） 印刷する
--cleanup 期限切れノートを削除してpush -

セキュリティ

対策 方式
URL推測不可 UUIDv4（122bit乱数）
検索エンジン除外 <meta name="robots" content="noindex, nofollow">
表示期限（即時） HTML内のJavaScriptで期限チェック、期限切れならコンテンツ非表示
表示期限（確実） --cleanup で期限切れHTMLをgit rm + push

公開URL形式

https://3kuni.github.io/p/{uuid}.html
  • 例: https://3kuni.github.io/p/a3f8b2c1-7e4d-4f1a-9b2e-1234567890ab.html

印刷レイアウト

  • 用紙: A4
  • ヘッダー: タイトル + 印刷日 + 公開期限
  • 本文: Markdown変換済みHTML（wikiリンクはノート名に変換）
  • フッター（右下固定）: QRコード + 「Web版はこちら」+ 期限表示

管理台帳（manifest.json）

{
  "notes": [
    {
      "uuid": "a3f8b2c1-...",
      "title": "ノート名",
      "created": "2026-03-30",
      "expires": "2026-04-29",
      "source_folder": "40_CORE"
    }
  ]
}

依存関係

ツール 用途
Python 3 スクリプト実行
markdown (pip) Markdown → HTML変換
qrcode + pillow (pip) QRコード生成
Google Chrome headlessモードでPDF変換
lp (macOS標準) プリンターへ印刷ジョブ送信
Git + GitHub Pages Web公開

処理詳細

Markdown変換時の処理

  1. YAML frontmatterの除去
  2. Obsidian wikiリンク note → ノート名のプレーンテキストに変換
  3. タイトルと同名のH1見出しを除去（印刷ヘッダーと重複するため）

期限切れ時の動作

  • Web版: JavaScriptが期限をチェックし「この文書の公開期限が終了しました」を表示
  • cleanup実行時: HTMLファイルをgit rmし、manifest.jsonから該当エントリを削除してpush
